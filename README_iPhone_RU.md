# UGR Messenger — iPhone / Safari PWA

Это веб-версия на основе `index.html` из Android-проекта. Использует тот же Supabase URL и publishable key, поэтому аккаунты и данные общие с Android-версией.

## Как выложить бесплатно
1. Создай репозиторий GitHub и загрузи **содержимое этой папки** (index.html, manifest.webmanifest, sw.js, icons).
2. В GitHub открой Settings → Pages.
3. В разделе Build and deployment выбери Deploy from a branch, ветку `main`, папку `/ (root)`, нажми Save.
4. Дождись публикации. GitHub Pages выдаст HTTPS-адрес вида `https://<имя-пользователя>.github.io/<репозиторий>/`.
5. Открой адрес на iPhone именно в Safari → Поделиться → На экран Домой → Добавить.

## Важно
- Сам архив ещё не опубликован в интернете: сначала нужен шаг хостинга, после него появится ссылка для девочки.
- Не выкладывай сюда или в публичный репозиторий Supabase service-role key, Firebase service-account JSON или пароли. В этой сборке используется publishable key, предназначенный для клиентского приложения; безопасность данных обеспечивается RLS и политиками Supabase.
- Эта PWA не добавляет отдельный Apple Push-канал. Внутренние уведомления и Realtime работают по существующей реализации, пока веб-приложение открыто; системные push при закрытом приложении требуют отдельной настройки Web Push и поддержки iOS.
- В iPhone Safari установка через «На экран Домой» бесплатна; публикация в App Store для этого не нужна.

## Обновление CHATFIX → DARK PREMIUM (этап 1)

- Обновлён визуальный стиль: графитовый фон, фиолетовые/голубые акценты, стеклянные панели.
- Добавлен блок разработчика `@ugr_creator` с переходом в профиль и отдельной кнопкой связи.
- Уведомления о сообщениях в текущем открытом чате больше не показываются поверх переписки.
- Realtime-подписка открытого чата подключается до загрузки истории, чтобы сократить риск пропуска сообщения в момент открытия.
- Дубли сообщений в DOM отсекаются по ID.
- Ответ RPC создания чата нормализуется, если сервер возвращает UUID, объект или массив.
- Сохранены CHATFIX-правила мобильного viewport, прокрутки и панели ввода.
- Обновлена версия кэша Service Worker, чтобы клиент получил новую оболочку.

**Ограничение:** полноценная гарантия создания обеих записей участников и отсутствие дублей зависит от SQL-функции `create_or_get_direct_conversation` и уникальных ограничений Supabase. SQL backend в этой сборке не менялся, потому что его текущая реализация/схема не была доступна для проверки. Верификационная отметка разработчика в этой версии — отображение frontend по имени `ugr_creator`, не защищённая серверной роль; безопасную выдачу отметок надо реализовать на backend отдельно.


## UGR 2.0 — добавленные функции (клиентская сборка)

- Поиск по тексту сообщений во всех загруженных личных чатах (по запросу к Supabase).
- Сохранённые сообщения и локальные реакции (хранятся в браузере данного устройства/аккаунта браузера, не синхронизируются с собеседником).
- Черновики отдельно для каждого диалога в localStorage.
- Редактирование и удаление собственных сообщений (зависит от Supabase RLS-разрешений).
- Ссылки на сохранённое сообщение открывают соответствующий чат и подсвечивают сообщение, если оно загружено в истории.

Эти функции не заменяют серверные функции/таблицы и не создают межустройственную синхронизацию локальных реакций или сохранённого.


## Дополнительный пакет UGR 2.0 (21.11.2026)

- Ответ на сообщение: вставляет выдержку из выбранного сообщения в поле ввода (простая текстовая цитата, без отдельной reply-связи в БД).
- Копирование текста сообщения через кнопку.

- Service Worker обновлён до cache v5.

Эти функции — клиентские; отдельные серверные таблицы для reply/pins не добавлены. Пересылка использует существующую таблицу messages и доступные политики Supabase.

## UGR 2.0 — локальные напоминания (дополнение)

В меню настроек открытого чата добавлены действия **«Добавить напоминание»** и **«Мои напоминания»**. Напоминание сохраняется в локальном хранилище этого браузера и связывается с чатом. Уведомление проверяется при входе в приложение и когда вкладка снова становится активной. Это не серверный push и не гарантируется, если браузер закрыт; данные не синхронизируются на другие устройства.


## Форматирование сообщений (добавлено)

- Панель быстрого форматирования в поле ввода: жирный (`**текст**`), курсив (`*текст*`), зачёркивание (`~~текст~~`) и моноширинный фрагмент (`` `код` ``).
- Отображение этих простых маркеров в сообщениях без вставки пользовательского HTML.
- Форматирование хранится в тексте сообщения, поэтому работает и в истории.

## UGR 2.0 — большой дополнительный пакет (21.11.2026)
- Личные заметки, привязанные к чату (не видны собеседнику).

Личные заметки, задачи и расписание сохраняются в localStorage текущего браузера и не синхронизируются между устройствами. Не считать их серверными функциями.
