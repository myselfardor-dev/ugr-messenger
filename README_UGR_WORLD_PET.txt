UGR MESSENGER — UGR WORLD / UGR PET v1

СОДЕРЖИМОЕ
- index.html: интегрированный раздел UGR WORLD с первым рабочим модулем UGR PET
- sw.js: обновлена версия PWA-кэша
- UGR_WORLD_PET_FUNCTIONS.sql: серверные RPC для получения первого питомца, выбора активного питомца и ухода за питомцем
- остальные файлы: исходные ресурсы проекта без удаления

ВАЖНО: перед публикацией
1. В Supabase SQL Editor выполни UGR_WORLD_PET_FUNCTIONS.sql ПОСЛЕ уже выполненной UGR_WORLD_INITIAL_MIGRATION.sql.
2. Убедись, что SQL завершился сообщением Success.
3. Замени файлы проекта содержимым этого архива (или загрузи обновлённые index.html и sw.js в текущий хостинг).
4. Обнови приложение. Если видишь старую версию, закрой PWA/вкладку и открой снова после обновления service worker.

ЧТО РАБОТАЕТ В ЭТОЙ ВЕРСИИ
- Кнопка UGR WORLD в боковой панели.
- Чтение каталога 6 питомцев из Supabase.
- Получение первого бесплатного питомца с именем.
- Начисление 25 UGR COINS за достижение «Первый питомец» на сервере.
- Просмотр личного питомца и его характеристик.
- Кормление, вода, игра, поглаживание и сон через серверные RPC.
- Начисление XP и повышение уровня.
- Прогресс достижения за 100 взаимодействий и серверная награда.
- Выбор активного питомца (для будущей коллекции).
- Обновление состояния через Supabase Realtime.

ПОКА НЕ РЕАЛИЗОВАНО
- Покупка дополнительных питомцев, магазин, одежда, мебель и эволюция.
- Общие питомцы чатов.
- Игры и их матчи.
- Реальное течение времени/автоматическое снижение шкал.
Это следующие этапы разработки; не считать их готовыми.

БЕЗОПАСНОСТЬ
- Клиент не получает прямых прав на запись в таблицы питомцев и валюты.
- Изменения выполняются SECURITY DEFINER RPC с проверкой auth.uid().
- Уход за питомцем ограничен серверным cooldown 12 секунд.

--- Обновление UGR WORLD (v2.1) ---
В этой версии интерфейс комнаты питомца, UGR SHOP и UGR COIN удалён из UGR WORLD.
Оставлены питомец, игры и блок наград. Для серверного постепенного изменения
потребностей питомца обязательно выполните файл UGR_WORLD_PET_NEEDS_MIGRATION.sql
в Supabase SQL Editor после предыдущих миграций UGR WORLD.

Новая механика: сытость, вода, энергия, настроение и чистота постепенно меняются
по времени; при следующем открытии мира сервер пересчитывает прошедшее время.
Сон восстанавливает энергию до 8 часов. Действия питомца меняют характеристики
на сервере. Для полного тестирования нужно выполнить SQL-миграцию.
