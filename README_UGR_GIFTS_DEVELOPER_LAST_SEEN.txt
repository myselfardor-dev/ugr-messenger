UGR MESSENGER — UGR GIFTS / ЧАТ РАЗРАБОТЧИКА / LAST SEEN

ЧТО ДОБАВЛЕНО В ВЕБ-ВЕРСИЮ
- Кнопка «Подарки» и каталог UGR Gifts.
- Покупка-отправка подарка другому пользователю за XP одной атомарной операцией.
- Коллекция полученных подарков в своём и чужих профилях.
- История отправленных и полученных подарков.
- XP читается из существующей public.user_xp. UGR Coin не используется и не меняется.
- Для обычного пользователя при входе автоматически создаётся личный чат с аккаунтом @ugr_creator.
- Чат разработчика закреплён сверху списка и показывает настоящее имя/аватар аккаунта разработчика.
- Last seen записывается в profiles.last_seen_at и отображается в чате/профиле.
- Кнопка уведомлений удалена из интерфейса. Realtime-подписка на уведомления сохранена.

ВАЖНО: СНАЧАЛА ВЫПОЛНИТЬ SQL
1. Открой Supabase → SQL Editor → New query.
2. Открой файл UGR_GIFTS_DEVELOPER_LAST_SEEN.sql.
3. Скопируй весь текст, вставь в SQL Editor и нажми Run.
4. Убедись, что Supabase показывает Success.
5. Только после этого загрузи index.html и остальные файлы архива на свой хостинг.

SQL создаёт каталог подарков и историю подарков, добавляет last_seen_at,
создаёт RPC для безопасного списания XP и RPC для автоматического чата разработчика.
Функция отправки подарка блокирует XP-строку пользователя и не допускает отрицательный баланс.

НЕ МЕНЯЕТСЯ:
- текущая функция claim_daily_xp и ежедневные +10 XP;
- существующие таблицы чатов и сообщений;
- UGR Coin и его кошельки;
- текущие функции питомца и UGR WORLD.

ПЕРВЫЙ ТЕСТ ПОСЛЕ УСТАНОВКИ
- Войти обычным аккаунтом: сверху должен появиться чат «Разработчик UGR».
- Открыть магазин: должен отображаться каталог и текущий баланс XP.
- Отправить недорогой подарок тестовому пользователю: XP уменьшится на цену, подарок появится в коллекции получателя и в истории.
- Открыть профиль другого пользователя: в статусе будет «В сети» либо время последней активности.
