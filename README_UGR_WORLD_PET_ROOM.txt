UGR MESSENGER — UGR WORLD / PET ROOM v2

ЧТО НОВОГО
- Добавлена комната для активного питомца.
- Визуальная комната рисуется CSS/emoji, без тяжёлых изображений и игровых движков.
- 3 темы стен: фиолетовая, неоновая, лесная.
- 3 варианта пола: тёмный, деревянный, звёздный.
- 12 видов декора: кровать, миски, мяч, растение, лампа, окно, ковёр, полка, постер, кактус, лунный свет.
- Можно добавлять предметы (до 12), убирать нажатием на предмет и сохранять.
- Настройки комнаты сохраняются в Supabase отдельно для каждого питомца.
- Анимация питомца работает локально в браузере и не отправляет сетевые события каждый кадр.

ПОРЯДОК УСТАНОВКИ
1. В Supabase SQL Editor выполни UGR_WORLD_PET_ROOM.sql.
   Предыдущие миграции UGR_WORLD_INITIAL_MIGRATION.sql и UGR_WORLD_PET_FUNCTIONS.sql уже должны быть выполнены.
2. Убедись, что SQL завершился Success.
3. Обнови файлы проекта содержимым архива (либо минимум index.html и sw.js, если остальные файлы не менялись).
4. Перезапусти веб-приложение/PWA. При старом интерфейсе закрой вкладку/PWA полностью и открой снова после обновления Service Worker.

ПРОВЕРКА
1. Открой UGR WORLD.
2. В блоке «Комната питомца» добавь несколько предметов.
3. Поменяй тему стен или пола.
4. Нажми «Сохранить комнату».
5. Закрой UGR WORLD, открой заново — оформление должно остаться.
6. Нажми на поставленный предмет — он уберётся из локальной раскладки; для сохранения удаления нажми «Сохранить комнату».

ВАЖНО
- Комната сохраняется в Supabase через защищённую RPC ugr_save_pet_room.
- RPC проверяет владельца питомца, допустимые темы, список мебели, координаты и лимит 12 предметов.
- Клиенту не выдаются прямые права INSERT/UPDATE/DELETE на ugr_pet_rooms.
- Таблица комнаты намеренно не включена в Realtime publication: для персонального декора обновление при повторном открытии достаточно и экономит Realtime quota.
- Комната пока не поддерживает перетаскивание мебели мышью/пальцем; предметы добавляются в заранее заданные места.
- Магазин, платная мебель, совместные комнаты, эволюция и полноценные игровые анимации — будущие этапы.
